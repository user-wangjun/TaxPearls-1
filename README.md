## 启动

已建立独立的 `.venv`。从本目录运行：

```powershell
.\.venv\Scripts\python.exe -m webapp --port 8016
```

打开 http://127.0.0.1:8016 。首次启动创建平台管理员，没有预置账号。按 `Ctrl+C` 停止；端口被占用时改用 `--port 8017`。

重新建立环境时：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
Copy-Item .env.example .env
```

复制配置仅在没有 `.env` 时执行，避免覆盖已经填写的配置。AI 默认关闭，本地解析、规则计算与报告不依赖外部模型。密钥是否已配置以本机 `.env` 为准，不在文档中展示；启用模型或邮件前核对相应配置与开关。2026-09-27 A12 验收已调用真实模型 4 次，仅发送现有合成夹具；未发送真实邮件。

## 目录

`src/` 是解析、数据模型、规则和报告；`webapp/` 是 API、存储和界面；`rules/` 是声明式规则；`tests/` 是回归测试；`scripts/` 是样例、RPA 和运维工具；`docs/` 是历史需求设计；`samples/` 区分合成材料与带来源的公开案例，不能混同；`prototype/` 是早期参考原型。

运行数据位于忽略的 `instance/`，报告在忽略的 `output/`。仅为测试生成的账号与审计库已清理，正式启动仍进入管理员初始化。
